# Seedbox Skill

把早期产品想法变成五维评分、证据缺口和下一步验证行动的 Agent Skill。

## 中文简介

Seedbox 是产品共创教练：先找想法中值得保留的创新内核，再判断当前版本该如何推进。适合独立开发者、产品经理和早期创业团队做产品初评或收窄 MVP。

本包从 Seedbox V3 评审逻辑整理而来，由你使用的 Agent 模型直接执行。不需要启动 Seedbox 网站、登录账号或单独配置模型 API。不同宿主模型的判断和评分可能不同。

## 方法

| 维度 | 回答的问题 |
|---|---|
| 需求 | 谁在什么场景下，有什么值得解决的问题？ |
| 解决方案 | 核心机制与替代方案相比有什么差别？ |
| 传播 | 首批用户在哪里，如何触达和传播？ |
| 商业化 | 谁付钱、为什么付、还缺什么证据？ |
| ROI | 开发与持续运营的投入是否值得验证？ |

先分析、后评分，每项 1–5 分。没有自动计算的总分门槛；“做 / 先验证 / 不做”结合关键风险判断。低分报告也会解释值得保留的机会，以及什么证据能改变判断。

## 输出

- 1–2 句话的整体判断。
- 五维评分表与理由。
- 核心功能、技术路径、风险与证据缺口。
- 做 / 不做建议与 MVP 切入点。
- 最低成本的下一次验证、观察指标和停止条件。

评分后的追问会沿用上下文；需要重评时说明判断变化的依据。

## 安装

先克隆仓库：

```bash
git clone https://github.com/Xinran0911/seedbox-skill.git
cd seedbox-skill
```

Codex 用户可将包复制到个人技能目录（先确认目标目录没有已有版本）：

```bash
mkdir -p ~/.codex/skills
cp -R seedbox ~/.codex/skills/seedbox
```

Claude Code 用户可复制到个人技能目录：

```bash
mkdir -p ~/.claude/skills
cp -R seedbox ~/.claude/skills/seedbox
```

其他支持 `SKILL.md` 的 Agent，可将整个 `seedbox/` 文件夹放到其技能目录。不同客户端的发现、重新加载与安装方式可能不同；本包没有验证所有客户端的兼容性。

## 示例提示词

```text
使用 $seedbox 评估这个想法：
做一个面向独立开发者的产品反馈整理工具。
把邮件、GitHub issue 和用户访谈归并为问题主题，
每个结论能点回原始反馈，帮助决定下一版先做什么。
我一个人开发，只有四周。请评估做不做，并收窄 MVP。
```

后续可以问：“如果先只接入 GitHub issue，哪些判断会改变？”

Claude Code 可用 `/seedbox` 调用。更完整的边界输入见 [示例请求](examples/prompts.md)；这些是输入示例，没有伪装成真实市场验证或客户端验收结果。

## 证据政策

区分用户输入、已核实资料、推断和未知。竞品现状、价格或市场规模等需要当前事实时，使用宿主可用的搜索工具查阅来源；工具不可用或请求失败时，明确说明缺口。没有数据时不编造 CAC、LTV、盈利周期或研究引用。

评分尺度是启发式评审锚点，不能当成成功概率或投资回报预测。来源版本与适配说明在 [评分尺度](seedbox/references/rubric.md)。

## 使用边界

适用于产品想法初评、方案比较和 MVP 收窄。网站部署、生产用户分析、自动上线和用户触达需要各自独立的工作流与授权。本包不包含生产数据、服务凭据或服务器操作脚本。
